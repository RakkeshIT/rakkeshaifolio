# Blog UI Asset Pack

## Hero
- `hero/developer-laptop-hero.png` — main hero artwork generated for the blog landing page.

## SVG Icons
Use the files in `icons/` for search, calendar, clock, tags, sharing, navigation and blog metadata.

## Glass UI
Use `glass/glass-card.svg`, `glass/glass-chip.svg`, and `glass/glass-button.svg` as decorative layers behind HTML/CSS components.

## Backgrounds
- `backgrounds/hero-gradient.svg` — dark hero backdrop
- `backgrounds/grid.svg` — subtle developer grid
- `backgrounds/glow-orb-blue.svg` — blue ambient glow
- `backgrounds/glow-orb-purple.svg` — purple ambient glow
- `backgrounds/blob.svg` — abstract decorative blob

## Technology
Simplified reusable SVG badges are provided under `tech/`.

## Suggested hero structure
1. `hero-gradient.svg` as the background.
2. `grid.svg` at low opacity.
3. Blue/purple glow orbs.
4. HTML text on the left.
5. `developer-laptop-hero.png` on the right.
6. Glass cards/chips layered over the illustration.

All SVG assets use transparent backgrounds where appropriate and can be recolored with CSS when using them as inline SVGs.
